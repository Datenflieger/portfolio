# Portfolio

This repository contains the source code for my personal portfolio website, available at [datenflieger.xyz](https://datenflieger.xyz).

## Features

- Responsive design with HTML, CSS, and JavaScript
- Showcases my projects, skills, and contact information
- Clean, modern layout

## Getting Started

To view the portfolio locally:

```bash
git clone https://github.com/Datenflieger/portfolio.git
cd portfolio
open index.html
```
